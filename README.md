# Fakhr (فخر) — Parent Support App

A mobile app for parents of children with special needs, providing care paths, professional directories, community support, and resources.

## Project Structure

- **fakhr-Capstone-Frontend** — Expo/React Native app
- **fakhr-capstone-Backend** — Node.js/Express API with MongoDB

## Features

- **Care Paths** — Personalized plans with tasks and check-ins
- **Directory** — Health centers and professionals (speech, OT, ABA, etc.)
- **Services** — Service catalog with provider discovery
- **Community** — Posts and support
- **Profile** — Child profiles, documents, settings

## Tech Stack

- **Frontend:** Expo, React Native, TypeScript, React Query
- **Backend:** Node.js, Express, MongoDB, Mongoose, JWT
