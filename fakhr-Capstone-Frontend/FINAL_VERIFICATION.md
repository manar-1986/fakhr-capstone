## ⚠️ If You See Arabic Text in Simulator

**The code is 100% English.** If you see Arabic text in the simulator, it's because:

### 1. Simulator Language Settings

**iOS Simulator:**

1. Open Simulator
2. Settings → General → Language & Region
3. iPhone Language → Select "English"
4. Restart Simulator

**Android Emulator:**

1. Open Emulator
2. Settings → System → Languages & input
3. Languages → Add Language → English
4. Move English to the top
5. Restart Emulator

### 2. Clear Cache and Rebuild

```bash
# Clear all caches
rm -rf node_modules .expo
npm install
npm start -- --clear
```

### 3. Rebuild App

```bash
# iOS
npm run ios -- --reset-cache

# Android
npm run android -- --reset-cache
```
